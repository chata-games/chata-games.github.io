## Design prompt

Use case: ui-mockup
Asset type: high fidelity desktop homepage design for the existing Czech browser game collection Chata Games.
Primary request: Overhaul the page design, using the supplied real game artwork. Create a complete polished website mockup that a developer will implement faithfully in HTML/CSS.
Input images: 1 reference existing brand cabin illustration; 2 reference Trollův sklep game cover; 3 reference Forest Rescue game cover; 4 reference Dali Game football cover. Preserve their recognizable artwork, use cropped images in cards.
Design: art-directed cozy indie game library, refined dark midnight green background, warm ivory typography and amber buttons, subtle thin borders, generous spacing, strong editorial serif headline paired with clean sans-serif navigation. Avoid purple gradients. Wide 1440px desktop page, compact header Chata Games left and Naše hry / O projektu / GitHub right. A spacious split hero: left eyebrow MALÉ HRY. VELKÁ DOBRODRUŽSTVÍ., large headline "Z chaty do jiného světa.", short Czech supporting copy, primary amber "Vybrat si hru" button; right large landscape cabin illustration with rounded corners using image 1. Below hero a slim trust strip "6 originálních her", "Přímo v prohlížeči", "Zdarma a open source". Then heading "Jaké dobrodružství si vybereš?" and small collection label. Grid of six games, three columns, two rows: Trollův sklep, Únikovka, Dali Game, Forest Rescue, Grunt: Cesta domů, Tvoje kariéra. Cards have large cropped artwork at top, small uppercase genre below, ivory game title, short Czech description, bottom "Hrát hru ↗" and subtle GitHub text link. For unprovided covers show cabin, jungle, football imagery from references. Finish with compact about strip and footer. No invented ratings, users, testimonials, account or search controls. All text and buttons must be plausible buildable HTML. Render entire page, front-on, no browser frame.
